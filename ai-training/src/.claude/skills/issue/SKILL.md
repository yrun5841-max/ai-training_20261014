# イシューを作る

## 手順

1. 頼まれた内容から、タイトルと本文の案を作る。わからないことがあれば、推測で埋めずにユーザーに聞く。
2. **GitHub に作る前に**、タイトルと本文をそのまま見せて、このまま作ってよいか確認する。
   - 直してほしいと言われたら、直した案をもう一度見せて確認をとる。
   - はっきり OK をもらうまで `gh issue create` は実行しない。
3. OK をもらったら、`gh issue create` で作る。本文は heredoc で渡す。

   ```bash
   gh issue create --title "<タイトル>" --body-file - <<'EOF'
   <本文>
   EOF
   ```

4. 作ったイシューの URL を伝える。

## 本文の書き方

日本語で書く。次の2つの見出しを必ず入れる。

```markdown
## やること

- <すること1>
- <すること2>

## 終わったと言える条件

- [ ] <確かめられる条件1>
- [ ] <確かめられる条件2>
```

- 「やること」には、何をするかを具体的に書く。
- 「終わったと言える条件」は、あとで見て達成したかどうかを判断できる形で書く（例: 「`npx vitest run` が通る」「申込者一覧に部署が表示される」）。「いい感じにする」のようなあいまいな書き方はしない。
- 背景や補足が必要なら、2つの見出しの前に短く書いてよい。
